# GovInfo Bulk Data — Guide

The Government Publishing Office (GPO) publishes machine-readable bulk
data for major legal collections — free, no key required for bulk files;
free API key for the service API.

## Collections
| Collection | URL | Contents |
|---|---|---|
| CFR | /bulkdata/CFR | Code of Federal Regulations (annual, XML) |
| eCFR | /bulkdata/ECFR | Electronic CFR (daily updates) |
| Federal Register | /bulkdata/FR | Daily journal (XML + PDF) |
| Statutes at Large | /bulkdata/STATUTE | Session laws since 1789 |
| Public Laws | /bulkdata/PLAW | Enacted public laws |
| Congressional Bills | /bulkdata/BILLS | Bill texts (USLM XML) |
| Bill Status | /bulkdata/BILLSTATUS | Legislative history |
| US Government Manual | /bulkdata/GOVMAN | Agency descriptions |

## Access
- Bulk root: https://www.govinfo.gov/bulkdata
- API docs: https://api.govinfo.gov/docs
- Link service (citation → URL): https://www.govinfo.gov/link-docs

*This repository documents access — the data itself is served by GPO.*
